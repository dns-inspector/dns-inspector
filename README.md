DNS Inspector is a free & open source iOS and iPadOS application that empowers you to perform
advanced DNS queries anytime and anywhere.

<img src="https://raw.githubusercontent.com/dns-inspector/dns-inspector/app-store/.github/iPhone67_1.png" alt="Screenshot of DNS Inspector showing the main view" height="300" />

Input a query and server address and get results in seconds. DNS Inspector will remember your recent
queries and last used DNS server to save you time. Plus, you can save a list of DNS servers for
quick access.

<img src="https://raw.githubusercontent.com/dns-inspector/dns-inspector/app-store/.github/iPhone67_2.png" alt="Screenshot of DNS Inspector showing the results of a lookup for apple.com" height="300" />

DNS Inspector will show you all information relating to your query and the results all without any
clutter.

<img src="https://raw.githubusercontent.com/dns-inspector/dns-inspector/app-store/.github/iPhone67_3.png" alt="Screenshot of DNS Inspector showing details of DNSSEC validation" height="300" />

DNS Inspector provides a full, native DNSSEC client for message authentication.

<img src="https://raw.githubusercontent.com/dns-inspector/dns-inspector/app-store/.github/iPhone67_4.png" alt="Screenshot of DNS Inspector showing a WHOIS response" height="300" />

Need to look up information about a domain name? No problem - DNS Inspector includes a bult-in WHOIS
client for easy lookups.

<img src="https://raw.githubusercontent.com/dns-inspector/dns-inspector/app-store/.github/iPhone67_5.png" alt="Screenshot of DNS Inspector showing a list of DNS servers" height="300" />

DNS Inspector supports traditional DNS on both UDP and TCP, and secure DNS servers with DNS over TLS (DoT) and DNS over HTTPS (DoH).
